VibeGap v0.5.1 修复 Codex 自动启动、接入状态判断与窗口拖动误触问题。

## 本次修复

- **Codex 启动更可靠**：源码接入使用安装时 Python 的绝对路径，不再依赖 Codex 启动环境中的 PATH。
- **减少启动等待**：除 SessionEnd 外的 Codex Hook 使用异步执行；冷启动补报保留原始事件时间，避免迟到的开始事件重新激活已结束任务。
- **接入状态更准确**：区分配置损坏、启动程序缺失、已配置未验证与近期收到 Hook。安装后的审核提示和失败提示直接显示在设置页。
- **长任务保持活跃**：Codex 日志持续新增内容时刷新运行会话的活跃时间，不重置弹窗倒计时，也不撤销手动隐藏。
- **拖动不再误开词书菜单**：左上角单击选择词书；移动达到 6 个屏幕像素后按拖动处理，松手或移回起点不会触发切换词书。
- **故障可排查**：Hook 失败阶段写入本地诊断日志，不记录提示词或对话内容。自动唤醒关闭时，设置页明确提示不会自动弹窗。

## 升级注意

1. Windows 用户下载安装包并选择 Codex 接入；源码用户更新安装后重新运行 `python vibegap/adapters/codex/install.py`。也可在小窗设置中点击 Codex 的“更新接入”。
2. **Hook 命令已变更，请在 Codex Hooks 页面重新审核信任一次**（CLI 使用 `/hooks`）。VibeGap 不会代写信任记录。
3. 升级保留现有学习进度与偏好。如果之前关闭了“自动唤醒”，请在设置中手动开启；默认弹出延迟为 18 秒。

持续写日志的长任务不会因开始时间超过 30 分钟而被清理；完全无新活动超过 30 分钟仍按过期会话处理。DSH 插件独立版本保持 0.1.3，本次无需重新安装 npm 插件。
